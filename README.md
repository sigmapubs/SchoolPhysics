# School Physics, Explained

Finished videos for the School Physics, Explained YouTube channel (SigmaEdu), stored here until the channel is live.
Each folder holds one ~10-minute video built from several related lessons:

- `video.mp4`: 1080p video with narration
- `captions.srt`: English captions
- `thumbnail.png`: 1280x720 thumbnail
- `description.txt`: YouTube description (chapters plus the full course unit list)
- `metadata.md`: title, playlists, visibility, end-screen notes
